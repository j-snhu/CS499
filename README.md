# CS 499 ePortfolio

This repository contains my **CS 499 Computer Science Capstone ePortfolio**, built using **GitHub Pages**. The ePortfolio presents a professional self-assessment and an enhanced technical artifact that demonstrates my growth throughout the Computer Science program.

The primary artifact featured is a **text-based adventure game**, including the original version and an enhanced version with improvements in software design, algorithms, and database integration.

## Enhancements Summary

- **Software Engineering and Design**  
  Refactored the game into a class-based structure with reusable methods for improved readability and maintainability.

- **Algorithms and Data Structures**  
  Added a shortest-path feature using a Breadth-First Search (BFS) algorithm and improved input validation and control flow.

- **Databases**  
  Integrated a SQLite database to store game results, including outcomes, move counts, and timestamps.
